# ML — Churn Predictor

## Folder structure
```
ml/
├── data/
│   ├── raw.csv                  # original Telco dataset
│   ├── churn_cleaned.csv        # after EDA + feature engineering
│   ├── X_train.csv              # training features
│   ├── X_test.csv               # test features
│   ├── y_train.csv              # training labels
│   └── y_test.csv               # test labels
├── model/                       # auto-generated by train.py
│   ├── pipeline.pkl             # sklearn Pipeline (scaler + XGBoost)
│   ├── shap_explainer.pkl       # SHAP TreeExplainer
│   ├── shap_importance.json     # top 15 feature importances
│   ├── feature_names.json       # ordered feature list
│   ├── metrics.json             # ROC-AUC, F1, precision, recall
│   ├── threshold.json           # optimal decision threshold
│   └── evaluation_report.png   # charts (after evaluate.py)
├── notebooks/                   # EDA notebooks go here
├── train.py                     # main training script
├── evaluate.py                  # evaluation charts + threshold table
└── README.md
```

## Setup
```bash
pip install pandas numpy scikit-learn xgboost shap mlflow imbalanced-learn joblib matplotlib seaborn
```

## Run training

```bash
python train.py
```

## Run evaluation
```bash
python evaluate.py
```

```bash
mlflow ui
# open http://localhost:5000
```

## Model info
- Algorithm: XGBoost with SMOTETomek resampling
- Features: 33 (encoded from 19 original columns)
- Imbalance handling: SMOTETomek + scale_pos_weight=2.76
- Threshold: auto-tuned for best F1 on test set
